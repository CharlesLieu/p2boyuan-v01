# v1.3 API 接口变更说明

版本：v1.3  
日期：2026-06-08  
范围：商家入驻、商家凭证查看、后台商家管理、后台凭证管理、商家权限收口

## 1. 统一说明

接口前缀：`/api/v1`  
认证方式：登录后携带 `Authorization: Bearer <token>`  
响应格式：

```json
{
  "success": true,
  "data": {},
  "message": "操作成功",
  "requestId": "uuid"
}
```

错误格式：

```json
{
  "success": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "字段格式不正确。",
    "fields": {}
  },
  "requestId": "uuid"
}
```

## 5. 已调整的旧接口权限

| 接口 | v1.3 调整 |
|---|---|
| `POST /api/v1/applications` | 仅 `SUPER_ADMIN` 可创建测试申请，商家不可创建客户申请 |
| `GET /api/v1/applications` | 商家不可访问客户申请列表 |
| `GET /api/v1/applications/{id}` | 商家不可访问客户申请详情 |
| `GET /api/v1/applications/{id}/logs` | 商家不可访问客户申请状态日志 |
| `POST /api/v1/applications/{id}/supplement` | 仅 `SALES` 和 `SUPER_ADMIN` 可提交客户申请补资料 |
| `POST /api/v1/applications/{id}/request-supplement` | 补资料处理对象仅支持 `SALES` |
| `POST /api/v1/attachments` | 商家不可上传客户申请附件 |

## 6. 状态枚举

### 6.1 商家入驻状态

| 状态 | 含义 |
|---|---|
| `PENDING_REVIEW` | 待平台审核 |
| `APPROVED` | 审核通过 |
| `REJECTED` | 已驳回 |

### 6.2 商家打款凭证状态

| 状态 | 含义 |
|---|---|
| `PENDING_CONFIRMATION` | 待确认 |
| `PAID` | 已打款 |
| `VOIDED` | 已作废 |
