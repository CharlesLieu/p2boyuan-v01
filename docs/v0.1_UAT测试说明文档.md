## 2. 状态流总览

### 2.1 正向主流程

1. 店家创建申请
2. 审核员指派业务员
3. 业务员开始验机
4. 业务员提交验机结果
5. 审核员审核通过
6. 出纳上传打款凭证
7. 出纳确认打款
8. 店家查看已打款状态和凭证

### 2.2 异常分支

| 分支 | 触发角色 | 结果 |
|---|---|---|
| 业务员退回补资料 | 业务员 | 申请回到补资料状态 |
| 审核员要求门店补资料 | 审核员 | 店家看到需补资料并提交补充说明 |
| 审核员要求业务员补资料 | 审核员 | 业务员看到需补资料并提交补充说明 |
| 审核员驳回申请 | 审核员 | 申请进入已驳回状态，不进入打款 |
| 出纳未上传凭证直接确认 | 出纳 | 系统应阻止确认打款 |
| 上传不支持文件 | 出纳 | 系统应提示附件格式或大小不正确 |

## 10. 失败与边界场景汇总

| Case | 场景 | 预期结果 |
|---|---|---|
| FAIL-01 | 错误密码登录 | 不允许进入系统 |
| FAIL-02 | 非授权角色访问其他角色页面 | 自动回到本角色页面 |
| FAIL-03 | 店家创建申请缺必填项 | 提示错误，不创建申请 |
| FAIL-04 | 审核员未选择业务员直接派单 | 提示请选择业务员 |
| FAIL-05 | 业务员未开始验机直接提交 | 不允许提交 |
| FAIL-06 | 非待审核申请点击审核通过/驳回 | 按钮不可用或提示状态不允许 |
| FAIL-07 | 出纳未上传凭证确认打款 | 不允许确认 |
| FAIL-08 | 出纳上传不支持文件 | 上传失败并提示 |
| FAIL-09 | 出纳上传超过 10MB 文件 | 上传失败并提示 |
| FAIL-10 | 超管选择不匹配处理人调整状态 | 保存失败或提示参数不正确 |

## 11. UAT 通过标准

### 11.1 功能通过标准

- 五类角色均可登录并进入对应工作台
- 店家可以提交申请和补资料
- 审核员可以派单、通过、驳回、要求补资料
- 业务员可以开始验机、提交验机、退回补资料
- 出纳可以上传图片/PDF 凭证、预览凭证、确认打款
- 超管可以重置测试数据和辅助恢复状态
- 每个关键动作后，列表状态、详情状态和日志记录保持一致

### 11.2 移动端通过标准

- 店家和业务员手机端无明显横向滚动
- 点击申请卡片后立即弹出详情
- 详情抽屉内信息可读，底部主操作清晰
- 登录页在手机端不再像桌面后台页面被拉长

### 11.3 桌面端通过标准

- 店家和业务员桌面端列表与详情不互相遮挡
- 审核员、出纳、超管桌面操作不出现主要按钮被截断
- 出纳上传凭证后可以预览

### 11.4 问题等级建议

| 等级 | 定义 | 示例 |
|---|---|---|
| 高 | 阻断主流程或造成错误状态 | 无法登录、无法确认打款、状态流错误 |
| 中 | 影响效率但可绕过 | 手机端详情难找、按钮位置不清晰 |
| 低 | 文案、样式、轻微体验问题 | 标签不够清楚、间距不美观 |
