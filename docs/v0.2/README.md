# v0.2 文档目录

本目录收口当前阶段的核心交付文档。v0.2 定位为“内部试运行版”，用于小范围真实或脱敏业务测试。

- `v0.2_内部试运行版_PRD.docx`：版本路线图里的 v0.2 PRD。
- `v0.2_标准完整PRD.md` / `v0.2_标准完整PRD.docx`：按最新商家权限口径整理后的完整 PRD。
