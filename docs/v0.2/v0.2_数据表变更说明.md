# v0.2 数据表变更说明

版本：v0.2  
日期：2026-06-08  
范围：商家入驻、商家打款凭证、商家权限收口

## 1. `stores` 表新增字段

| 字段 | 类型 | 是否为空 | 说明 |
|---|---|---|---|
| `onboarding_status` | `varchar(40)` | 否 | 商家入驻状态：`PENDING_REVIEW`、`APPROVED`、`REJECTED` |
| `payment_method` | `varchar(40)` | 是 | 收款方式，例如 `BANK`、`ALIPAY`、`WECHAT` |
| `payment_account` | `varchar(120)` | 是 | 原始收款账号，仅后台保存，前端返回时需脱敏 |
| `payment_account_name` | `varchar(120)` | 是 | 收款户名 |
| `payment_bank_or_channel` | `varchar(120)` | 是 | 开户行或收款渠道 |

索引：

| 索引字段 | 说明 |
|---|---|
| `onboarding_status` | 后台按入驻状态筛选商家 |

## 2. 新增表：`merchant_onboarding_applications`

| 字段 | 类型 | 是否为空 | 说明 |
|---|---|---|---|

| `applicant_name` | `varchar(100)` | 否 | 申请人姓名 |
| `applicant_phone` | `varchar(40)` | 否 | 申请人手机号 |
| `applicant_id_number` | `varchar(80)` | 否 | 申请人证件号 |
| `merchant_name` | `varchar(100)` | 否 | 商家名称 |
| `merchant_address` | `varchar(255)` | 否 | 商家地址 |
| `contact_name` | `varchar(100)` | 否 | 联系人 |
| `contact_phone` | `varchar(40)` | 否 | 联系电话 |
| `payment_method` | `varchar(40)` | 否 | 收款方式 |
| `payment_account` | `varchar(120)` | 否 | 收款账号 |
| `payment_account_name` | `varchar(120)` | 否 | 收款户名 |
| `payment_bank_or_channel` | `varchar(120)` | 是 | 开户行或收款渠道 |
| `id_card_front_file` | `json` | 否 | 身份证正面文件信息 |
| `id_card_back_file` | `json` | 否 | 身份证反面文件信息 |
| `qualification_file` | `json` | 否 | 商家资质文件信息 |
| `status` | `varchar(40)` | 否 | 入驻状态 |
| `reviewer_user_id` | `bigint` | 是 | 审核人，关联 `users.id` |
| `reviewed_at` | `timestamp` | 是 | 审核时间 |
| `review_note` | `text` | 是 | 审核通过意见 |
| `reject_reason` | `text` | 是 | 驳回原因 |
| `created_at` | `timestamp` | 是 | 创建时间 |
| `updated_at` | `timestamp` | 是 | 更新时间 |

索引：

| 索引字段 | 说明 |
|---|---|
| `status` | 按审核状态筛选 |
| `store_id, status` | 商家端查询最新入驻申请 |
| `status, created_at` | 后台按状态和时间查看 |

文件字段 JSON 示例：

```json
{
  "fileName": "license.pdf",
  "filePath": "/demo/merchant/license.pdf",
  "mimeType": "application/pdf",
  "fileSize": 512000
}
```

## 3. 新增表：`merchant_payment_vouchers`

用途：保存商家可查看的打款凭证。出纳确认客户申请打款后，系统会自动生成对应商家凭证；超级管理员也可以后台手动新增或作废凭证。

| 字段 | 类型 | 是否为空 | 说明 |
|---|---|---|---|
| `id` | `uuid` | 否 | 主键 |
| `voucher_no` | `varchar(40)` | 否 | 凭证编号，唯一 |
| `store_id` | `uuid` | 否 | 关联 `stores.id` |
| `payout_record_id` | `uuid` | 是 | 关联 `payout_records.id` |
| `related_business_no` | `varchar(80)` | 是 | 关联业务编号，例如客户申请编号 |
| `amount` | `decimal(12,2)` | 否 | 打款金额 |
| `status` | `varchar(40)` | 否 | 凭证状态 |
| `paid_at` | `timestamp` | 是 | 打款时间 |
| `payee_name` | `varchar(120)` | 否 | 收款方名称 |
| `payee_account_masked` | `varchar(120)` | 否 | 脱敏收款账号 |
| `payer_name` | `varchar(120)` | 是 | 付款方名称 |
| `voucher_file` | `json` | 否 | 凭证文件信息 |
| `remark` | `text` | 是 | 备注 |
| `void_reason` | `text` | 是 | 作废原因 |
| `created_by_user_id` | `bigint` | 是 | 创建人，关联 `users.id` |
| `created_at` | `timestamp` | 是 | 创建时间 |
| `updated_at` | `timestamp` | 是 | 更新时间 |

索引：

| 索引字段 | 说明 |
|---|---|
| `voucher_no` | 唯一凭证编号 |
| `status` | 按凭证状态筛选 |
| `store_id, status` | 商家端查询本商家凭证 |
| `status, paid_at` | 后台按状态和打款时间查询 |

状态枚举：

| 状态 | 含义 |
|---|---|
| `PENDING_CONFIRMATION` | 待确认 |
| `PAID` | 已打款 |
| `VOIDED` | 已作废 |

## 4. 旧表业务口径调整

| 表 | 调整说明 |
|---|---|
| `applications` | 商家不再创建客户申请；测试申请由超级管理员创建或由种子数据生成 |
| `status_logs` | 补资料处理对象不再写入商家，客户申请补资料流转给业务员 |
| `attachments` | 商家不再上传客户申请附件；商家入驻和凭证文件以 JSON 文件元数据保存到对应商家表 |
| `payout_records` | 出纳确认打款后仍保留原客户申请打款记录，同时生成 `merchant_payment_vouchers` 供商家查看 |

## 5. 数据隔离规则

| 角色 | 数据可见范围 |
|---|---|
| 商家 | 只能查看自己 `store_id` 对应的入驻资料和打款凭证 |
| 业务员 | 只处理分配给自己的客户申请任务 |
| 审核员 | 查看客户申请审核流程，不管理商家入驻 |
| 出纳 | 查看待打款客户申请，确认打款并上传凭证 |
| 超级管理员 | 管理账号、商家入驻、商家凭证、测试数据和状态 |
