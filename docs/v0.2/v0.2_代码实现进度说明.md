## 1. 已完成后端能力

### 1.1 账号治理

已完成：

- 用户表补充账号治理字段：
  - `password_updated_at`
  - `disabled_at`
  - `disabled_reason`
- 超级管理员可查看账号列表。
- 超级管理员可创建账号。
- 超级管理员可更新账号展示名、角色、状态、门店绑定、业务员绑定。
- 超级管理员可停用账号。
- 超级管理员可重置账号密码。
- 停用账号不能登录。
- 重置密码后旧密码失效。

权限规则：

- 店家账号必须绑定门店。
- 业务员账号必须绑定业务员档案。
- 非超级管理员不能管理账号。

### 1.2 权限边界

已完成：

- 店家不能访问客户申请列表、申请详情、申请日志、客户申请附件。
- 业务员只能查看自己被指派的申请。
- 出纳不能执行审核动作。
- 审核员不能确认打款。
- 商家只能查看本商家的打款凭证。
- 附件上传按角色限制模块：
  - 业务员：`INSPECTION`、`SUPPLEMENT`
  - 出纳：`PAYOUT`、`VOUCHER`
  - 审核员、超级管理员：全部模块
  - 店家：不能上传客户申请附件

### 1.3 申请编号

已完成：

- 新申请编号改为日期 + 当日序号格式。
- 示例：`A202606080001`
- 同一天内按已有最大序号递增。
- 兼容旧演示编号，不让旧编号影响新序号计算。

### 1.4 附件中心

已完成：

- 按申请查看附件列表。
- 查看单个附件元数据。
- 获取附件预览 / 下载地址。
- 附件列表返回上传人信息。

接口：

- `GET /api/v1/applications/{applicationId}/attachments`
- `GET /api/v1/attachments/{attachmentId}`
- `GET /api/v1/attachments/{attachmentId}/download`

### 1.5 操作日志

已完成：

- 新增统一 `StatusLogService`。
- 状态流转日志统一记录：
  - 操作人
  - 操作角色
  - 操作动作
  - 原状态
  - 新状态
  - 备注
  - 扩展元数据
- 后台创建申请和超级管理员手动改状态也纳入统一日志写法。

### 1.6 列表筛选

已完成：

- 申请列表支持：
  - `status`
  - `storeId`
  - `salesAgentId`
  - `ownerRole`
  - `keyword`
  - `createdFrom`
  - `createdTo`
  - `limit`
- 打款列表支持：
  - `status`
  - `storeId`
  - `keyword`
  - `paidFrom`
  - `paidTo`
  - `limit`
- 商家入驻列表支持：
  - `status`
  - `storeId`
  - `keyword`
  - `createdFrom`
  - `createdTo`
  - `limit`
- 商家打款凭证列表支持：
  - `status`
  - `storeId`
  - `keyword`
  - `paidFrom`
  - `paidTo`
  - `limit`
- 商家自己的凭证列表支持：
  - `status`
  - `keyword`
  - `paidFrom`
  - `paidTo`
  - `limit`

所有筛选都在当前角色原本可见范围内生效，不扩大权限。
