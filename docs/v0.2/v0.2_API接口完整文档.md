# v0.2 API 接口完整文档

版本：v0.2  
日期：2026-06-08  
适用系统：手机分期回收平台 / 业务测试版  
技术栈：Vue H5 + PHP Laravel API + MySQL

本文档是 v0.2 的完整 API 接口说明，覆盖登录、申请单、验机、审核、打款、附件、商家入驻、商家打款凭证、超级管理员等接口。

---

## 1. 通用约定

### 1.1 Base URL

本地或服务器部署后统一使用：

```text
http://服务器地址/api
```

示例：

```text
http://101.201.69.137/api
```

### 1.2 认证方式

除 `GET /health` 和 `POST /v1/auth/login` 外，其余接口都需要登录 Token。

请求头：

```http
Authorization: Bearer {token}
Content-Type: application/json
```

文件上传接口使用：

```http
Authorization: Bearer {token}
Content-Type: multipart/form-data
```

### 1.3 标准响应格式

成功：

```json
{
  "success": true,
  "data": {},
  "message": null,
  "requestId": "req-demo-001"
}
```

失败：

```json
{
  "success": false,
  "message": "参数错误",
  "errors": {
    "amount": ["打款金额不能超过申请贷款金额。"]
  },
  "requestId": "req-demo-002"
}
```

### 1.4 角色说明

| 角色 | 代码 | 说明 |
|---|---|---|
| 店家 / 商家 | `STORE` | 提交申请、补资料、查看本商家打款凭证 |
| 业务员 | `SALES` | 到店验机、提交验机结果、补资料 |
| 审核员 | `AUDITOR` | 派单、审核通过、驳回、要求补资料 |
| 出纳 | `CASHIER` | 查看待放款记录、确认打款、上传凭证 |
| 超级管理员 | `SUPER_ADMIN` | 账号、数据重置、状态调整、商家审核、凭证管理 |

### 1.5 测试账号

| 角色 | 账号 | 密码 |
|---|---|---|
| 店家 | `store001` | `123456` |
| 业务员 | `sales001` | `123456` |
| 审核员 | `audit001` | `123456` |

## 5. 申请单接口

### 5.1 GET `/v1/applications`

获取申请单列表。店家角色不能访问该接口。

查询参数：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `status` | string | 否 | 按状态筛选，支持单个状态或英文逗号分隔多个状态 |
| `storeId` | string | 否 | 按门店筛选，在当前角色可见范围内生效 |
| `salesAgentId` | string | 否 | 按业务员筛选，在当前角色可见范围内生效 |
| `ownerRole` | string | 否 | 按当前处理角色筛选 |
| `keyword` | string | 否 | 按申请编号、客户姓名、手机号、设备型号、IMEI、门店名称搜索 |
| `createdFrom` | string | 否 | 创建时间起始值，ISO 日期时间字符串 |
| `createdTo` | string | 否 | 创建时间结束值，ISO 日期时间字符串 |
| `limit` | number | 否 | 返回条数，默认 50，最大 100 |

请求示例：

```http
GET /api/v1/applications?status=PENDING_PAYOUT&keyword=A20260530007&limit=20
```

## 6. 附件中心接口

### 6.1 POST `/v1/attachments`

上传申请相关附件。店家角色不能访问该接口；业务员仅可上传 `INSPECTION`、`SUPPLEMENT`，出纳仅可上传 `PAYOUT`、`VOUCHER`，审核员和超管可上传全部模块。

表单字段：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `applicationId` | string | 是 | 申请 ID |
| `module` | string | 是 | `APPLICATION` / `INSPECTION` / `SUPPLEMENT` / `PAYOUT` / `VOUCHER` / `OTHER` |
| `file` | file | 是 | PNG、JPG、WEBP、PDF，最大 10MB |
| `remark` | string | 否 | 备注 |

请求示例：

```http
POST /api/v1/attachments
Authorization: Bearer 1|token-example
Content-Type: multipart/form-data

applicationId=9d0a-application-001
module=INSPECTION
remark=设备正面照片
file=@device-front.png
```

响应示例：

```json
{
  "success": true,
  "data": {
    "id": "attachment-001",
    "applicationId": "9d0a-application-001",
    "module": "INSPECTION",
    "fileName": "device-front.png",
    "filePath": "attachments/device-front.png",
    "mimeType": "image/png",
    "fileSize": 245000,
    "url": "/storage/attachments/device-front.png"
  },
  "message": "附件上传成功",
  "requestId": "req-upload-001"
}
```

## 11. 状态枚举

### 11.1 申请单状态

| 状态 | 说明 |
|---|---|
| `SUBMITTED` | 已提交 |
| `ASSIGNED` | 已指派业务员 |
| `INSPECTION_IN_PROGRESS` | 验机中 |
| `INSPECTION_SUBMITTED` | 验机已提交 |
| `SUPPLEMENT_REQUIRED` | 需补资料 |
| `SUPPLEMENT_SUBMITTED` | 补资料已提交 |
| `APPROVED` | 审核通过 / 待放款 |
| `REJECTED` | 已驳回 |
| `PAID` | 已打款 |

### 11.2 验机状态

| 状态 | 说明 |
|---|---|
| `ASSIGNED` | 已派单 |
| `IN_PROGRESS` | 验机中 |
| `SUBMITTED` | 已提交 |
| `REJECTED` | 验机驳回 |

### 11.3 打款状态

| 状态 | 说明 |
|---|---|
| `PENDING` | 待打款 |
| `PAID` | 已打款 |

### 11.4 商家入驻状态

| 状态 | 说明 |
|---|---|
| `PENDING_REVIEW` | 待审核 |
| `APPROVED` | 已通过 |
| `REJECTED` | 已驳回 |

### 11.5 商家打款凭证状态

| 状态 | 说明 |
|---|---|
| `PENDING_CONFIRMATION` | 待确认 |
| `PAID` | 已打款 |
| `VOIDED` | 已作废 |

## 12. 权限边界

1. 店家只能访问商家端接口，不能访问完整申请单接口。
2. 店家只能查看本商家的打款凭证。
3. 店家不能查看用户完整申请资料、合同、账单、逾期、锁机或解锁操作。
4. 业务员只能处理自己被指派的验机和补资料工作。
5. 审核员负责派单、审核、驳回和要求补资料。
6. 出纳只能处理打款列表和确认打款。
7. 超级管理员拥有全部演示数据管理和流程调整权限。
