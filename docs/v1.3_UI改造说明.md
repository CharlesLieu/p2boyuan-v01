# v1.3 H5 UI 改造说明

## 改造范围

- 商家端：入驻、凭证、我的。
- 业务员端：任务中心、录单台、我的。
- 出纳端：打款中心、凭证、我的。
- 审核员与超级管理员：保留电脑后台风格，仅优化布局稳定性和视觉层级。

## 主要变化

- 手机 H5 页面统一为浅蓝色业务风格：顶部标题、白色概览卡、横向状态标签、卡片列表、底部 Tab、纵向详情。
- 业务员点击订单卡片后直接打开详情，不再需要滚动到页面底部查看。
- 出纳打款页保留凭证上传与预览，确认打款金额不得超过待打款金额。
- 商家端只展示商家入驻状态、本商家的打款凭证和我的商家信息。
- 审核员和超级管理员电脑后台修复窄桌面下列表与详情互相覆盖的问题。

## 权限不变

- 商家不能查看客户完整申请资料、合同、账单、逾期、锁机或解锁信息。
- 商家不能补客户资料。
- 审核员要求补资料仍只回到业务员。
- 出纳仍需上传凭证后才能确认打款。
